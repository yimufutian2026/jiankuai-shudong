| 我现在很烦，说不上来为什么。 | 没关系，烦是一种信号。我们不用急着找出原因。可以先做三次深呼吸，感受这股烦躁在身体哪个位置：是胸口闷、眉头紧，还是胃里发紧？轻轻把手放在那里，陪它待一会儿。愿意的话，试着给这股情绪打个分（0-10分），我们一起看看它。 |
| 我总是很焦虑，怎么办？ | 焦虑常来自对未来的不确定。我们可以用简快疗法的'抽离'视角：想象你飘到半空中，看着此刻焦虑的自己——你只是一个正在经历焦虑的人，你比你的焦虑更大。然后问自己：此刻我能做的一小件可控的事是什么？哪怕只是喝口水、整理桌面。 |
| 我很难过，一直走不出来。 | 难过需要被允许，不需要急着'走出来'。先陪自己待一会儿：给它一个名字（比如'委屈'或'失落'），给它一个形状和颜色。当你愿意，我们可以一起看看这个难过后面的需要是什么——是渴望被看见、被理解，还是想要一个拥抱？ |
| 我经常否定自己，觉得自己不够好。 | 这个'不够好'的声音，通常不是事实，而是某个早期经验形成的旧信念。我们可以做一个'信念松绑'练习：写下这句话，问自己——它是真的吗？有什么证据？它对我有帮助吗？如果去掉它，我可以是谁？慢慢给旧信念一个更温和的替代。 |
| 我容易生闷气，憋在心里。 | 生闷气常常是'没被好好表达的界限'。我们可以试着：①承认'我有情绪，这是正常的'；②用'我句式'表达：'我感到____，是因为____，我希望____'；③如果暂时说不出口，先用书写把它倒出来。情绪不是要压下去，而是要被看见和安放。 |
| 什么是时间线？可以怎么用它？ | 时间线是简快疗法里常用来回顾与调整的工具。你可以想象一条线，一端是过去，一端是未来，此刻在中间。我们用它来做'力量回访'：回到过去某个你成功度过难关的时刻，把当时的资源、勇气、智慧带回来，用于现在和未来。 |
| 可以带我做一个力量回访练习吗？ | 可以。请闭上眼睛，回想人生中某一次你克服困难、感到有力量的时刻（不一定要很大）。找到那个画面，感受当时身体的感觉、呼吸的节奏。然后想象把这份'力量、信心、智慧'打包带回现在的自己身上，轻轻收进心里。慢慢睁眼，感受身体的变化。 |
| 什么是检定语言模式？对我有用吗？ | 检定语言模式是NLP里通过提问松动'僵化表达'的技术。当你总说'我没办法''我不可能''所有人都不喜欢我'这类绝对化的句子时，我会陪你轻轻发问：'是所有人吗？有没有哪怕一个例外？''是真的没办法，还是暂时没想到办法？'——让被卡住的表达松动出新的空间。 |
| 我总说'我没办法改变'，怎么破？ | 我们试试把'我没办法'换成'我暂时还没想到办法'。这个小小的措辞变化，会从'死路'变成'路上'。再问自己：如果奇迹发生，我已经改变了，那时的我会做的第一件小事是什么？把它当作可以尝试的第一步。 |
| 什么是亲和感/同步？ | 亲和感是沟通中让对方感到被理解、愿意敞开的基础。做法：先别急着给建议，先'跟上'对方——复述他的感受（'听起来你很委屈'）、适当放慢语速、匹配语气。被真正听懂，人才愿意继续往下走。这既是沟通技巧，也是一种尊重。 |
| 可以教我正念呼吸放松吗？ | 可以。找个舒服的姿势，轻轻闭眼。吸气4秒（想象把气息吸到腹部），屏住2秒，缓缓呼气6秒。重复几次，感受肩膀慢慢下沉。如果走神了，轻轻把注意力带回呼吸就好，不用责怪自己。这就是最简单的落地放松。 |
| 我总讨好别人，改不掉。 | 讨好背后，常常是一个'怕被抛弃、怕不被喜欢'的旧信念。可以做一个'价值确认'练习：列出三件'我就是我'就值得被喜欢的证据（不靠讨好换来的）。慢慢把'讨好才能被爱'换成'我值得被爱，本身就是价值'。 |
| 我和家人/伴侣总吵架，怎么办？ | 冲突里通常不是对错问题，而是需要没被看见。简快的思路：先按下暂停键，各自冷静；再各自说出'我真正想要的是什么'（比如被尊重、被重视、被理解）。很多时候，我们把'要爱'表达成了'指责'。先表达需要，再谈解决方案。 |
