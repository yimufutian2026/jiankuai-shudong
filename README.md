# 简快树洞

一个**免费开源**的心理自助网页平台，定位为心理陪伴与自助支持（非医学诊断）。

本网页项目为免费开源项目，代码开源共享，仅用于心理陪伴与自助支持，不包含任何商业收费内容。

## 功能模块

| 模块 | 说明 |
|------|------|
| 数字人专家对话 | 5 位多领域心理专家（儿童/青少年/婚恋/家庭/综合），简快身心积极疗法风格回应：共情 → 问题聚焦 → 例外资源探索 → 小目标设定 → 行动建议，支持多轮对话 |
| 危机识别 | 内置自毁类关键词库，触发时停止正常对话并转危机话术（全国心理援助热线 12356 / 急救 120 / 报警 110） |
| 心理自测中心 | 6 套测评：情绪与压力速测、抑郁情绪筛查（含危机条目）、儿童心理状态（家长版）、青少年心理状态、婚恋关系满意度、家庭教育方式 |
| 免费公益咨询 | 填写意向时间/咨询类型/诉求后提交，展示咨询师微信 13737983666；线下地址广西宜州区第三人民医院，支持线上视频 |
| 我的记录 | localStorage 本地保存测评历史与咨询记录，支持 JSON 导出与一键清除（不上传服务器） |
| 隐私合规 | 启动免责确认页；数据仅存本地；危机识别与转介说明 |

## 风险边界

- 本平台所有回答**不做医学诊断、不承诺疗效**。
- 免费公益咨询**不能替代专业心理咨询与危机干预**。
- 危机求助：全国心理援助热线 **12356**（24小时）/ 急救 **120** / 报警 **110**。

## 技术栈

- Next.js 16 (App Router) + React 19 + TypeScript 5
- Tailwind CSS 4 + shadcn/ui
- 数据存储：浏览器 localStorage（纯前端，无后端 API）

## 目录结构

```
src/
├── app/                        # 页面路由
│   ├── page.tsx                # 首页
│   ├── layout.tsx              # 根布局（含免责确认）
│   ├── globals.css             # 全局样式（品牌主题色）
│   ├── chat/page.tsx           # 专家选择页
│   ├── chat/[expertId]/page.tsx# 对话页（危机检测）
│   ├── assessments/page.tsx    # 自测中心列表
│   ├── assessments/[assessmentId]/page.tsx  # 测评答题/结果页
│   ├── appointment/page.tsx    # 免费公益咨询
│   └── records/page.tsx        # 我的记录（导出/清除）
├── components/
│   ├── bottom-nav.tsx          # 底部导航
│   ├── disclaimer-provider.tsx # 免责确认弹窗
│   └── ui/                     # shadcn/ui 组件
└── lib/
    ├── chat-engine.ts          # 简快疗法对话引擎
    ├── crisis.ts               # 危机关键词库与话术
    ├── assessments.ts          # 6 套测评量表数据
    ├── experts.ts              # 专家数据
    └── storage.ts              # localStorage 封装
```

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开 http://localhost:5000 。
